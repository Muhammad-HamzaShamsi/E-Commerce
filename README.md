# 🛍️ RedStore: E-Commerce Website

![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![Responsive](https://img.shields.io/badge/Design-Responsive-success)

A responsive front-end for a fashion and sportswear store called **RedStore**, built with plain **HTML and CSS**. It's a practice project in layout techniques (Flexbox), responsive design and product-page UI.

## Sections

- 🏠 **Hero banner:** "Give Your Workout a New Style!" with a call-to-action button
- 🗂️ **Categories:** featured category images
- ⭐ **Featured products:** product cards with ratings and prices
- 🆕 **Latest products:** a grid of new arrivals (shoes, t-shirts, watches, socks, …)
- 🎯 **Exclusive offer:** a promotional banner
- 💬 **Testimonials:** customer reviews
- 🤝 **Brands:** partner brand logos
- 📱 **Footer:** app store links and site info

## Run locally

No build step needed:

```bash
git clone https://github.com/Muhammad-HamzaShamsi/E-Commerce.git
cd E-Commerce
# open index.html in your browser, or serve it:
python -m http.server 8000   # http://localhost:8000
```
